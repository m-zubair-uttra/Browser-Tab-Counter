# Chrome Tab Counter 📊

A lightweight, privacy-first Chrome extension that displays live tab and window statistics directly in your browser toolbar.

---

## ✨ Features

* **Live Counter:** Real-time badge counter showing active open tabs and windows.
* **Usage Statistics:** Monitor all-time opened tabs and maximum concurrent open tabs.
* **Badge Customization:** Built-in color picker to personalize badge background and text colors.
* **Pinned Tabs Support:** Accurately counts pinned tabs within your current window.
* **100% Private:** Zero tracking, no browsing history collection, and no third-party data sharing.

---

## 🆕 What's New

* Added pinned tabs to current window counts.
* Color picker support for badge background and text colors.
* Modernized popup UI design for cleaner statistics view.

---

**1. 🚀 Installation & Local Development**

Open Google Chrome and go to chrome://extensions/.

Toggle on Developer mode in the top-right corner.

Click Load unpacked and select the cloned project directory.

Pin the extension to your toolbar to view the live counter badge.
